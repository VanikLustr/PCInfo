# PC Info

Небольшая программа с тёмным интерфейсом, которая показывает сведения о компьютере и обновляет загрузку в реальном времени.

## Возможности

- **Обзор** — система, пользователь, процессор, ОЗУ, время работы, загрузка ЦП/памяти/системного диска.
- **Процессор** — модель, сокет, ядра и потоки, частоты, кэш, температура, число процессов и загрузка каждого потока.
- **Память** — ОЗУ и файл подкачки, живая полоса заполнения.
- **Диски** — разделы, занятое место, скорость чтения и записи.
- **Сеть** — интерфейсы, IPv4, MAC, скорость соединения, принятые/отправленные данные и текущая скорость.
- **Оборудование** — видеокарта, экран, материнская плата, BIOS, физические накопители, модули ОЗУ, батарея.
- **Отчёт** — сохранение всех сведений в текстовый файл.

## Запуск

1. Установите Python 3.9+ (на Windows — с галочкой **Add Python to PATH**).
2. Запустите `start.bat` или выполните в папке:

```bash
python pc_info.py
```

Если модуля `psutil` нет, программа предложит установить его сама. Вручную:

```bash
pip install -r requirements.txt
```

## Примечания

- Подробные данные об оборудовании (плата, BIOS, модули ОЗУ, видеокарта) читаются через PowerShell/WMI и доступны в Windows. На Linux/macOS основные вкладки работают, часть аппаратных данных будет недоступна.
- Температура процессора показывается только при наличии датчиков, доступных через `psutil`.
- Все данные остаются на компьютере; для работы не нужен интернет.
