# PC Info

Небольшая программа с живым мониторингом компьютера: процессор, память, диски, сеть и подробные сведения об оборудовании.

## Возможности

- **Обзор** — система, пользователь, процессор, ОЗУ, время работы, загрузка ЦП/памяти/системного диска.
- **Пульс** — график загрузки процессора и памяти за последние 90 секунд.
- **Процессор** — модель, сокет, ядра и потоки, частоты, кэш, температура, число процессов и загрузка каждого потока.
- **Память** — ОЗУ и файл подкачки, живая полоса заполнения.
- **Диски** — разделы, занятое место, скорость чтения и записи.
- **Сеть** — интерфейсы, IPv4, MAC, скорость соединения, принятые/отправленные данные и текущая скорость.
- **Оборудование** — видеокарта, экран, материнская плата, BIOS, физические накопители, модули ОЗУ, батарея.
- **Отчёт** — сохранение всех сведений в текстовый файл.

## Темы

В правом верхнем углу есть выбор темы:

- **Тёмная** — спокойный синий акцент.
- **Светлая** — светлый интерфейс с мягкими тенями.
- **AMOLED** — настоящий чёрный фон и голубой акцент.
- **Pie** — тёплая оранжево-коричневая палитра, острые углы и фирменная подпись внизу.

У тем `Тёмная`, `Светлая` и `AMOLED` карточки, кнопки и таблицы скруглены. В теме `Pie` скругления отключены — только острые углы. Выбранная тема запоминается между запусками.

## Шрифты

Используются несколько шрифтов: **Bahnschrift** для заголовка, **JetBrains Mono** для цифр, метрик и технических подписей, **Segoe UI** для обычного текста.

## Звуки

- Звуки есть только у событий: запуск программы, переключение вкладок и пасхалка.
- Кнопки специально **не озвучиваются**.
- Рядом с выбором темы есть галочка **«Звуки»**, чтобы отключить их.
- Состояние звука запоминается.

## Пасхалка

На рабочем столе (или рядом с `pc_info.py`) может лежать `donut.py` — вращающийся ASCII-пончик.

Открыть его можно так:

- **5 раз кликнуть по заголовку** «Сведения о компьютере»;
- или нажать **Ctrl+Shift+D**.

Окно пончика закрывается кликом или клавишей **Esc**. Вращение идёт в реальном времени.

Ещё одна мелочь: **Ctrl+T** переключает темы по кругу.

## Запуск

1. Установите Python 3.9+ (на Windows — с галочкой **Add Python to PATH**).
2. Запустите `start.bat` или выполните в папке:

```bash
python pc_info.py
```

Если модуля `psutil` нет, программа предложит установить его сама. Вручную:

```bash
pip install -r requirements.txt
```

## Примечания

- Подробные данные об оборудовании (плата, BIOS, модули ОЗУ, видеокарта) читаются через PowerShell/WMI и доступны в Windows. На Linux/macOS основные вкладки работают, часть аппаратных данных будет недоступна.
- Температура процессора показывается только при наличии датчиков, доступных через `psutil`.
- Настройки темы и звука хранятся в `%APPDATA%\PCInfo\settings.json` (на Windows).
- Все данные остаются на компьютере; для работы не нужен интернет.
